PWA Приложение калькулятора

Автономное приложение для расчета стоимости аренды ковров. Работает без интернета, устанавливается на главный экран.

Как установить приложение:

Android

  • Chrome → меню (⋮) → "Установить приложение"
  • Firefox → меню (☰) → "Установить"
  • Яндекс.Браузер → меню (⋯) → "На экран"

iPhone/iPad

  • Safari → Поделиться (📤) → "На экран «Домой»"
  • Chrome → меню (⋯) → "Добавить на начальный экран"

Windows/Mac

  • Chrome → меню (⋮) → "Установить МИРУМ Калькулятор"
  • Edge → меню (⋯) → "Приложения" → "Установить"

Для заключения договора потребуются:

  • Реквизиты компании - полное наименование, ИНН, КПП, ОГРН
  • Подписант - ФИО, основание полномочий (директор, доверенность)
  • Адрес объекта - точный адрес, название, вывеска
  • Режим работы - часы работы объекта, удобное время для замен
  • Контактное лицо - ФИО, телефон для связи с курьером
  • Особые условия - доступ на объект, требования безопасности

Что включено в стоимость аренды:

  • Бесплатная доставка - привозим чистые ковры прямо к вам
  • Профессиональная установка - наши курьеры установят ковры
  • Регулярная замена - забираем грязные, привозим чистые
  • Санация и чистка - все ковры проходят санитарную обработку
  • Замена при износе - бесплатно меняем изношенные ковры
  • Полный пакет документов - договор, акты, счета для бухгалтерии
  • Гибкий график - подстроимся под ваш режим работы
  • Круглосуточная поддержка - всегда на связи в Telegram
