# МИРУМ Калькулятор - PWA приложение

## 📱 О приложении
Progressive Web App (PWA) для расчета стоимости аренды ковров. 
Внутренний инструмент для менеджеров компании МИРУМ.

## 📁 Структура файлов
/pwa/
├── mirum-pwa.html # Основной файл PWA
├── service-worker.js # Service Worker
└── README.md # Эта инструкция

## 🚀 Установка и настройка

### 1. Размещение на сервере
1. Создайте папку `/pwa/` в корне сайта
2. Скопируйте все файлы из этой папки
3. Убедитесь, что все пути правильные

### 2. Проверка PWA
1. Откройте: `https://ваш-сайт.ru/pwa/mirum-pwa.html`
2. Проверьте на [pwabuilder.com](https://www.pwabuilder.com/)
3. Все показатели должны быть зелеными

### 3. Обновление данных (цен)
1. Отредактируйте объект `priceData` в файле `mirum-pwa.html`
2. Обновите `CACHE_VERSION` в том же файле (строка с константами)
3. Загрузите обновленный файл на сервер

## 🔧 Технические особенности

### Service Worker
- Регистрируется для `/pwa/` директории
- Кэширует основные файлы для офлайн-работы
- Автоматически обновляет кэш при изменении `CACHE_VERSION`

### Manifest (`site.webmanifest`)
- Расположен в корне сайта
- Указывает на `/pwa/mirum-pwa.html` как точку входа
- Содержит все необходимые иконки и метаданные

### SEO
- PWA страница запрещена для индексации в `robots.txt`
- Установлены мета-теги `noindex, nofollow`
- Не влияет на SEO основного сайта

## 🔄 Обновление приложения

### Минорные обновления (данные)
1. Обновите данные в `mirum-pwa.html`
2. Измените `CACHE_VERSION` (увеличьте версию)
3. Загрузите на сервер
4. Service Worker автоматически обновит кэш

### Мажорные обновления (функционал)
1. Обновите HTML/CSS/JS
2. Измените `CACHE_VERSION` значительно (например, v3.0 → v4.0)
3. Загрузите все файлы
4. Пользователи получат уведомление об обновлении

## 🐛 Отладка

### DevTools (Chrome/Firefox)
1. Откройте DevTools (F12)
2. Перейдите в Application → Service Workers
3. Проверьте статус регистрации
4. Просмотрите кэшированные файлы

### Проверка офлайн-режима
1. В DevTools: Network → Offline
2. Обновите страницу
3. Должна загрузиться из кэша

### Проверка установки
1. Откройте приложение
2. Проверьте, появляется ли кнопка установки
3. Проверьте работу в standalone режиме

### Частые проблемы
1. **PWA не устанавливается**: Проверьте HTTPS и Service Worker
2. **Иконки не отображаются**: Проверьте пути в `site.webmanifest`
3. **Не работает офлайн**: Проверьте регистрацию Service Worker
4. **Старые данные**: Очистите кэш браузера и обновите `CACHE_VERSION`
